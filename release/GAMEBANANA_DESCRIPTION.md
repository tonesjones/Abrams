# Blue Spot Monster Abrams

Turns Abrams into a big blue-furred, purple-spotted monster tank — fan-inspired by the classic animated blue monster look.

## Features

- Full-body **blue fur recolor** with **purple spots** (head, coat, upper body, lower body)
- Matching **gun + teeth** palette tweaks
- Custom **hero select / gloat / critical portraits**

## Install

1. Extract `pak69_dir.vpk` into `Deadlock/game/citadel/addons/`
2. Rename the pak number if it conflicts with another mod
3. Launch and play Abrams

## Notes

- Texture + portrait mod only (stock model/animations)
- Client-side cosmetic
- Not affiliated with Valve or any animation studio
